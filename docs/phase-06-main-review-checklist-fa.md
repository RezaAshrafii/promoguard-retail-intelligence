# چک‌لیست بازبینی اصلی Phase 6

این سند نقطهٔ توقف عمدی پروژه برای بازبینی یک مدل سطح بالا است. در این نقطه، هدف اثبات ارزش
تجاری uplift نیست؛ هدف این است که روش، مرز ادعا و گزارش قابل بررسی باشند.

## آنچه انجام شده

- دادهٔ واقعی Criteo با checksum ثبت‌شده استفاده شده است.
- test کامل و قفل‌شده شامل ۲٬۰۹۶٬۹۳۹ ردیف ارزیابی شده است.
- ویژگی‌ها فقط `f0` تا `f11` هستند و `exposure` حذف شده است.
- S-Learner و T-Learner پیاده‌سازی شده‌اند.
- انتخاب مدل فقط با validation انجام شده و T-Learner انتخاب شده است.
- AUUC/Qini و baseline تصادفی پنج‌تایی گزارش شده‌اند.
- پوشش treatment/outcome برای تمام splitها ثبت شده است.
- gate منفی حفظ شده و `promotion_allowed=false` است.

## پرسش‌های باز برای مدل بازبین

1. آیا تعریف Qini و نحوهٔ محاسبهٔ AUUC با convention انتخاب‌شده کاملاً شفاف و درست است؟
2. آیا baseline پنج permutation برای این حجم و ساختار داده کافی است یا باید confidence interval داشته باشد؟
3. آیا split وابسته به ترتیب canonical فایل، برای benchmark قابل قبول است یا باید split مستقل‌تری طراحی شود؟
4. آیا مدل‌های linear برای این benchmark بیش از حد ضعیف‌اند و مقایسه با learner غیرخطی لازم است؟
5. چه bootstrap یا آزمون حساسیتی باید پیش از هر ادعای علمی اضافه شود؟
6. آیا گزارش فعلی برای مقاله/ارائه مناسب است یا باید فقط به‌عنوان engineering benchmark معرفی شود؟
