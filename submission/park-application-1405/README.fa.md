# بسته ارائه ایده — PromoGuard Retail Intelligence

این پوشه برای ارائه تا ۱۳ شهریور ۱۴۰۵ آماده شده است. هر فایل یک وظیفه روشن دارد و هیچ‌کدام نباید
بدون شخصی‌سازی اطلاعات فردی، نام دانشگاه، تاریخ و لینک‌های نهایی ارسال شود.

## ترتیب استفاده

1. `form-response-fa.md` را با اطلاعات شخصی واقعی کامل کن و پاسخ‌ها را در فرم رسمی وارد کن.
2. `one-page-brief-fa.md` را به‌عنوان خلاصه‌ای که داور سریع می‌خواند، ضمیمه یا در سامانه کپی کن.
3. `architecture-and-90day-plan-fa.md` را فقط وقتی بفرست که جزئیات فنی یا برنامه اجرای آزمایشی
   می‌خواهند.
4. `risk-register-fa.md` پاسخ آماده برای پرسش‌های ریسک و بلوغ طرح است.
5. `demo-script-2min-fa.md` را برای ضبط یا ارائه دموی دو دقیقه‌ای تمرین کن.
6. `evidence-index.md` نقشه اتصال هر ادعا به کد، تست یا artifact واقعی است.

## قانون ارائه

- «نمونه اولیه قابل اجرا» ادعا می‌شود، چون کد، API، داشبورد و اجرای داده واقعی وجود دارد.
- «اثبات اثر اقتصادی» ادعا نمی‌شود، چون هنوز customer pilot، cost واقعی و طراحی آزمایش کنترل‌شده
  نداریم.
- «بازار هدف» و «درخواست pilot» فرضیه و برنامه اعتبارسنجی هستند، نه مشتری یا قرارداد فعلی.
- هر جای‌خالی داخل `<...>` باید پیش از ارسال با واقعیت تکمیل شود.

## خروجی فعلی محصول

نسخه فعلی پروژه `v0.4.0-phase-04` است و روی پنل عمومی dunnhumby اجرا شده است. برای اجرای
دوباره از `python -m demo.phase4_smoke` استفاده کن. گزارش آن در
`reports/phase-04/demo-smoke.json` قرار دارد.
